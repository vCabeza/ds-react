# Tabs

Compound tabs for switching panels: `Tabs`, `TabList`, `Tab`, `TabPanel`.

Variants are strictly **`Pill`** and **`Underline`**. Selecting a tab shows the matching panel (same public `id` on `Tab` and `TabPanel`). There is no `mobile` prop — Storybook mobile stories use a constrained preview frame that mirrors production media-query metrics.

Shared stack, setup, and accessibility (roles, keyboard, panel association) live under **Overview**.

## How it works

- `Tabs` owns controlled/uncontrolled selection (`selectedKey` / `defaultSelectedKey` / `onSelectionChange`) and variant context.
- `TabList` handles Arrow Left/Right (wrap), Home, and End.
- DOM ids use `ds-tab-*` / `ds-tabpanel-*` so tab and panel never share one HTML `id`; the public `id` prop stays the selection key.
- Responsive gaps/metrics are CSS media-query only.

## Usage

```tsx
import { Badge, Tab, TabList, TabPanel, Tabs } from 'ds-react'

export function WorkspaceTabs() {
  return (
    <Tabs
      variant="Pill"
      defaultSelectedKey="emails"
      aria-label="Workspace"
      onSelectionChange={(key) => console.log(key)}
    >
      <TabList>
        <Tab id="emails" badge={<Badge variant="Neutral">12</Badge>}>
          Emails
        </Tab>
        <Tab id="files" badge={<Badge variant="Negative">!</Badge>}>
          Files
        </Tab>
        <Tab id="edits">Edits</Tab>
      </TabList>
      <TabPanel id="emails">Emails content</TabPanel>
      <TabPanel id="files">Files content</TabPanel>
      <TabPanel id="edits">Edits content</TabPanel>
    </Tabs>
  )
}
```

## Props (`Tabs`)

- **variant** — `"Pill"` | `"Underline"` (default `"Pill"`).
- **selectedKey** / **defaultSelectedKey** / **onSelectionChange**
- **aria-label** — Accessible name for the tab list.
- **className** / **children**

`Tab` / `TabList` / `TabPanel` compose under `Tabs`.
