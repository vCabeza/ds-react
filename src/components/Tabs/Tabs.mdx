# Tabs

Compound tabs pattern for switching content panels. Part of the design system public API: `Tabs`, `TabList`, `Tab`, `TabPanel`.

Variants are strictly **`Pill`** and **`Underline`**. Selecting a tab shows the matching panel (same public `id` on `Tab` and `TabPanel`).

## How it works

- `Tabs` owns controlled/uncontrolled selection (`selectedKey` / `defaultSelectedKey` / `onSelectionChange`) and variant context.
- `TabList` is `role="tablist"` and handles Arrow Left/Right (wrap), Home, and End.
- `Tab` triggers selection; `TabPanel` shows when its `id` matches the selected key.
- DOM ids use `ds-tab-*` / `ds-tabpanel-*` so tab and panel never collide on the HTML `id` attribute, while the public `id` prop stays the selection key.
- Responsive list gaps and tab metrics use CSS media queries only (no JS `mobile` prop).

## Technologies

- React + TypeScript (raw selection, keyboard, and ARIA — no React Aria)
- Plain CSS + design tokens (`ds-react/styles`)
- WAI-ARIA tabs pattern (APG)

## Accessibility

- Roles: `tablist`, `tab`, `tabpanel`.
- `aria-selected` and roving `tabIndex` (selected `0`, others `-1`).
- Keyboard: Arrow Left/Right with wrap, Home/End; Enter/Space via native `<button>`.
- Pass `aria-label` on `Tabs` when there is no visible list label.
- Panels use `hidden` when inactive; `aria-controls` / `aria-labelledby` associate tab ↔ panel.
- Badge in a tab must not replace a clear label. See repository `ACCESSIBILITY.md`.

## Usage

```tsx
import 'ds-react/styles'
import { Badge, Tab, TabList, TabPanel, Tabs } from 'ds-react'

export function WorkspaceTabs() {
  return (
    <Tabs
      variant="Pill"
      defaultSelectedKey="emails"
      aria-label="Workspace"
      onSelectionChange={(key) => console.log(key)}
    >
      <TabList>
        <Tab id="emails" badge={<Badge variant="Neutral">12</Badge>}>
          Emails
        </Tab>
        <Tab id="files" badge={<Badge variant="Negative">!</Badge>}>
          Files
        </Tab>
        <Tab id="edits">Edits</Tab>
      </TabList>
      <TabPanel id="emails">Emails content</TabPanel>
      <TabPanel id="files">Files content</TabPanel>
      <TabPanel id="edits">Edits content</TabPanel>
    </Tabs>
  )
}
```

## Props (`Tabs`)

- **variant** — `"Pill"` | `"Underline"` (default `"Pill"`).
- **selectedKey** / **defaultSelectedKey** / **onSelectionChange**
- **aria-label** — Accessible name for the tab list.
- **className** / **children**

`Tab` / `TabList` / `TabPanel` compose under `Tabs`. Prefer Storybook stories under this section for interactive and Figma-matrix demos.
