# Badge

Static status label for short counts, tags, or severity cues. Commonly composed into a `Tab` via the `badge` slot.

Badge is **non-interactive** (a `<span>`). Size and padding adapt with CSS media queries only — there is no `mobile` prop.

## How it works

- Renders a native `<span>` with variant classes (`Neutral` | `Positive` | `Negative`).
- Desktop (`min-width: 769px`) and mobile (`max-width: 768px`) metrics come from tokens in CSS.
- When used inside `Tab`, pass `<Badge variant="…">` into `Tab`’s `badge` prop; choose the Badge variant on Badge itself.

## Technologies

- React + TypeScript
- Plain CSS + design tokens (`ds-react/styles`)
- No interaction library (static content)

## Accessibility

- Not a control: no keyboard handler or focus ring of its own.
- Visible text is the accessible name contribution when nested in a tab.
- Keep labels short; color is not the only cue — variants also change surface tokens.
- Contrast uses `OnNeutral` on surface tokens (see repository `ACCESSIBILITY.md`).

## Usage

```tsx
import 'ds-react/styles'
import { Badge } from 'ds-react'

export function Example() {
  return (
    <>
      <Badge variant="Neutral">12</Badge>
      <Badge variant="Positive">New</Badge>
      <Badge variant="Negative">!</Badge>
    </>
  )
}
```

On a tab:

```tsx
<Tab id="emails" badge={<Badge variant="Neutral">12</Badge>}>
  Emails
</Tab>
```

## Props

- **children** — Visible label content.
- **variant** — `"Neutral"` | `"Positive"` | `"Negative"` (default `"Neutral"`).
- **className** — Extra class names.
- Other native `span` attributes are forwarded.
