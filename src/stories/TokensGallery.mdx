# Tokens Gallery

Living reference for design tokens used across `ds-react`. Prefer CSS custom properties (`var(--ds-…)`) in component styles; use the TypeScript modules (`colorTokens`, `spacingTokens`, `typographyTokens`) for typed access and tooling.

## How it works

- CSS source of truth for runtime styles: `src/styles/tokens.css` (shipped as `ds-react/styles` / `ds-react/styles/tokens.css`).
- TypeScript mirrors spacing, color, and typography scales under `src/tokens/`.
- Components must consume tokens via `var(--ds-…)` (or documented semantic tokens such as `--Inverse`) instead of hardcoded visual values, except documented exceptions (e.g. sr-only clips, rare Figma colors without a token).

## Technologies

- CSS custom properties
- TypeScript token modules
- Storybook for visual browsing (this gallery)

## Accessibility

- Tokens encode contrast pairs used by Button, Badge, and Tab (text ≥ 4.5:1, UI/focus ≥ 3:1 where specified).
- Focus width/offset tokens (`--ds-focus-*`) back `data-focus-visible` rings.
- Motion duration tokens should respect `prefers-reduced-motion` in components.
- This gallery canvas is documentation, not an interactive control (a11y addon is set to `todo` here).

## Usage

Install styles once in the host app:

```tsx
import 'ds-react/styles'
```

In CSS:

```css
.example {
  padding: var(--ds-space-s);
  color: var(--OnNeutral);
  font-family: var(--ds-font-family);
}
```

In TypeScript:

```ts
import { spacingTokens, colorTokens, typographyTokens } from 'ds-react'

spacingTokens.S.px // 16
```

## Categories

- **Color** — semantic surfaces and on-colors (`Inverse`, `SurfaceHigh`, `OnNeutral`, …).
- **Spacing** — `0` … `2XL` (`--ds-space-*`).
- **Typography** — `body-s` / `body-m` and related metrics.
- **Focus / target / motion** — shared interaction tokens used by primitives.
